# Sudoku

A clean, modern, and fully responsive Sudoku web application built from scratch using Vanilla HTML, CSS, and JavaScript. Designed with a focus on User Experience (UX), this app features a distraction-free minimalist interface that works perfectly on both desktop and mobile devices without requiring any scrolling.

## Features

* **Fully Responsive UI:** Uses dynamic viewport heights and CSS clamp functions to ensure the entire game fits perfectly on a single screen no scrolling required on phones, tablets, or laptops.
* **Auto-Save (Local Storage):** Never lose your progress. The game automatically saves your current board state, difficulty level, and theme preference whenever you make a move or reload the page.
* **Dark & Light Mode:** Seamlessly toggle between a crisp light theme and a sleek dark mode for comfortable playing at any time of day.
* **Multiple Difficulties:** Choose between Easy, Medium, and Hard puzzles.
* **Smart Input & Validation:** 
  * Play using the on-screen soft numpad, physical keyboard numbers, or arrow keys to navigate the grid.
  * Automatically checks your answers when the board is completely filled.
* **Zero Dependencies:** Built entirely with pure HTML, CSS, and JavaScript. No React, no frameworks, no libraries.
